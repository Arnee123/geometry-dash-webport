Geometry Dash webport - Vercel project

Files:
- index.html: the webport page
- vercel.json: basic Vercel static-site configuration

Deploy:
1. Upload index.html and vercel.json to the root of your GitHub repository.
2. In Vercel, import that GitHub repository.
3. Keep the framework preset as Other and leave the build and output settings blank/default.
4. Deploy.

Note: The HTML uses external webport assets and WebAssembly from its configured upstream host. This project does not include a separate copy of all those assets.
